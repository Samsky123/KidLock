# 安装教程（侧载 APK）

本教程面向普通家长，不需要编程基础。全程约 10 分钟；「强力锁」为可选进阶步骤。

> 只从本仓库的 **Releases** 页面下载 APK。不要安装网盘、群聊里来路不明的改包——
> 本应用不联网，若某个「儿童管控」安装包要求联网或索取短信权限，基本可以判定是假的。

---

## 0. 准备

| 项 | 要求 |
|---|---|
| 手机系统 | Android 7.0 及以上（Android 10–14 体验最完整） |
| 安装包 | `KidLock-v1.4.1.apk`（约 5.7 MB） |
| 电量 | 建议 30% 以上 |
| 旧版本 | 若装过其他签名的 KidLock，先卸载，否则会提示签名冲突 |

---

## 1. 下载 APK

1. 用手机浏览器打开本仓库页面。
2. 进入 **Releases / 发行版**。
3. 下载最新版本的 `.apk` 文件（不要下载 Source code 压缩包）。

如果 Releases 里还没有 APK，可以按 [README 的构建章节](../README.md#从源码构建) 自行编译，
或请有 Android 开发环境的朋友帮忙构建。

---

## 2. 允许安装未知应用

Android 默认禁止浏览器安装 APK。点开下载完成的文件，系统会弹出提示：

- **「为了安全，你的手机不允许安装未知来源的应用」** → 点「设置」；
- 找到 **允许来自此来源的应用** → 打开开关；
- 返回，点「安装」。

各品牌大致路径（不同版本略有差异）：

| 品牌 | 路径 |
|---|---|
| 小米 / Redmi（MIUI、HyperOS） | 设置 → 应用设置 → 应用管理 → 右上角 ⋮ → 特殊权限 → 安装未知应用 → 选择浏览器 → 允许 |
| 华为 / 荣耀（HarmonyOS、EMUI） | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 → 选择浏览器 → 允许 |
| OPPO / 一加 / realme（ColorOS） | 设置 → 安全 → 安装外部来源应用 → 选择浏览器 → 允许 |
| vivo / iQOO（OriginOS） | 设置 → 更多设置 → 权限管理 → 安装未知应用 → 选择浏览器 → 允许 |
| 三星（One UI） | 设置 → 应用程序 → 特殊访问权限 → 安装未知应用 → 选择浏览器 → 允许 |

> Android 14 可能提示「此应用专为旧版 Android 打造」，这是 targetSdk 33 的正常提示，
> 点「仍然安装」即可。

安装完成后先**不要**急着打开，继续下一步。

---

## 3. 首次启动与家长账号

1. 打开「儿童手机管控」，会直接进入答题页（此时还没有题，会提示先由家长配置）。
2. 点页面底部的 **「家长入口」**。
3. 首次使用显示「创建家长账号」：
   - 账号：自己容易记的，例如 `parent`；
   - 密码：**至少 6 位**，只有家长知道；
   - 再输一次确认。
4. 点「创建并进入」。

密码用 PBKDF2 加盐哈希保存在本机，不保存明文；连续输错 5 次会锁定 60 秒。
**请务必记住密码**——本地没有找回功能（见第 8 节）。

---

## 4. 配置管控规则

进入家长首页后，点 **「题库与出题」**：

| 设置项 | 建议 |
|---|---|
| 每轮可玩时长 | 先设 15–30 分钟，确定有效后再调整 |
| 教材版本 | 与孩子课本一致；不确定选「不分版本」 |
| 孩子年级 | 一至六年级 |
| 本轮各科题量 | 三个数字框，填 `0` 表示该科不出；例如语文 2、数学 1、英语 1 |
| 出题范围 | 可选「全部单元」或按册 / 单元选择；语文按整册 |
| 题目难度上限 | 低年级建议「简单」或「中等」 |
| 优先出错题 | 建议开启，错题会反复出现 |

底部会实时显示「本轮共 N 道题 · 答完可用 M 分钟」。确认后保存。

### 按 App 限时（可选）

家长首页 →「应用限时设置」：

1. 点「去授予使用情况访问权限」，在系统设置里找到本应用并允许；
2. 勾选要限制的应用（抖音、快手、微信、游戏等），设置每日分钟数；
3. 保存。

未授权时该功能自动跳过，不影响整机答题解锁。

---

## 5. 必做：开启「到点弹题」权限

Android 10 起，应用默认不能从后台拉起界面。不开这个权限，时间到了题目弹不出来，
管控会看起来「设了但没用」。

1. 家长首页会显示「到点弹题权限：未开启」；
2. 点 **「开启『到点弹题』权限（必需）」**；
3. 在系统页面找到「儿童手机管控」，打开 **「显示在其他应用上层 / 悬浮窗」**；
4. 返回应用，状态变为 **「已开启 ✓」** 才算完成。

### 建议同时开启

| 权限 | 路径 | 作用 |
|---|---|---|
| 通知 | 设置 → 应用 → 儿童手机管控 → 通知 | Android 13+ 显示倒计时通知 |
| 全屏通知 | 设置 → 应用 → 特殊权限 → 全屏通知 | 锁屏时也能拉起答题页（Android 14 需手动确认） |
| 自启动 | 手机管家 / 应用管理 → 自启动 | 重启后仍能管控（国产 ROM 必开） |
| 电池优化 | 设置 → 电池 → 电池优化 → 本应用 → 不优化 | 防止后台服务被系统杀掉 |

国产 ROM 的「后台保活」设置名称各不相同（自启动、关联启动、后台运行、省电策略），
原则是：**允许自启动 + 允许后台运行 + 不限制耗电**。

---

## 6. 开始使用

1. 家长首页点右上角 **「退出登录」**；
2. 回到答题页，孩子做完题后点选项提交；
3. 全部答对 → 显示解锁，倒计时开始；
4. 时间到 → 自动弹回答题页。

答错的题会排到本轮队尾，必须答对才能结束；同时记入错题本，连续答对 2 次才移出。

## 7. 可选：强力锁（Device Owner）

普通模式下，孩子按 Home 键会闪一下桌面，然后被自动拉回。
如果希望 Home / 最近任务 / 通知栏**在系统层面完全失效**，并且防止卸载，可配置 Device Owner。

> ⚠️ 这一步会显著提高「恢复普通手机」的成本，请确认确实需要再做。
> 配置后无法通过 adb 或应用商店卸载，只能先在家长页解除。

### 前提

手机上**不能有任何账号**，包括：

- 小米 / 华为 / Google 等系统账号；
- 抖音、小红书、微信等应用内登录的账号；
- 部分机型的「查找设备」也会被算作账号。

最稳妥的顺序：**恢复出厂 → 跳过所有账号登录 → 安装本应用 → 执行命令**。
否则会报：

```text
Not allowed to set the device owner because there are already some accounts on the device
```

### 步骤

1. 手机「设置 → 关于手机」连点「版本号」7 次，开启开发者选项；
2. 开发者选项里打开 **USB 调试**；
3. 电脑安装 adb（macOS：`brew install android-platform-tools`；Windows：Android SDK Platform-Tools）；
4. 数据线连接手机，手机上点「允许 USB 调试」；
5. 电脑执行：

```bash
adb devices
# 应能看到设备序列号，状态为 device

adb shell dpm set-device-owner com.example.kidlock/.AdminReceiver
# 成功返回：Success: Device owner set to package com.example.kidlock/.AdminReceiver
```

6. 回到 App，家长页的「防退出（强力锁）」卡片会显示已启用。

### 解除

家长登录 → 家长首页 → 「防退出（强力锁）」→ **「解除强力锁」** → 确认。

设上之后 `adb shell dpm remove-active-admin` 会被系统拒绝（`SecurityException`），
这是 Android 的保护机制，防止别人拿电脑随手解除家长设置。所以**务必确认应用内的解除入口可用**。

## 8. 忘记密码 / 重置 / 卸载

### 忘记家长密码

本地没有找回渠道，只能清空应用数据（题目配置、错题本会一起丢失）：

```bash
adb shell pm clear com.example.kidlock
```

没有电脑时：卸载重装（若已配置强力锁，必须先解除，否则卸载会失败）。

### 卸载

1. 先打开 App → 家长登录 → 解除强力锁（如果配置过）；
2. 再在系统里卸载，或执行：

```bash
adb uninstall com.example.kidlock
```

### 彻底恢复普通手机

解除强力锁 → 卸载应用。若无法解除，只能恢复出厂设置。

## 9. 故障排查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 提示「解析包时出现问题」 | 下载不完整 / 系统低于 Android 7 | 重新下载；确认系统版本 |
| 提示「应用未安装」 | 与已装版本签名冲突 / 空间不足 | 卸载旧版后重装；清理空间 |
| 到点不弹题 | 未开悬浮窗；后台被限制 | 开启「显示在其他应用上层」、自启动、关闭电池优化 |
| 按 Home 能回桌面 | 普通模式的固有限制 | 需要彻底禁止请配置 Device Owner |
| 重启后不管控 | 自启动被拦截 | 手机管家允许自启动；重新打开一次 App |
| 倒计时停住 / 时间不准 | 后台服务被杀 | 电池优化设为「不优化」；锁定后台任务 |
| 设置 Device Owner 报 accounts | 手机上还有账号 | 恢复出厂，跳过账号登录后重试 |
| 卸载失败 | 已配置 Device Owner | 先在家长页解除强力锁 |
| 答题页没有题目 | 三科题量都是 0 / 范围里无题 | 重新设置题量，或把范围改为「全部单元」 |
| 家长入口点不开 | 登录页被回弹 | 属于正常防退出行为，重新点一次并尽快输入 |

更多技术细节见 [技术说明](技术说明.md)；若问题仍未解决，请在 Issue 中附上：
手机型号、系统版本、复现步骤、`adb logcat -s KidLock` 的相关日志。

## 10. 安全提醒

- 本应用**不申请联网权限**，不会上传任何数据；请勿安装声称「需要联网激活」的改包。
- Device Owner 是系统级高权限，配置前请确认自己理解解除方式。
- 本工具用于家庭内部的时间管理，请勿用于监控他人设备。
- 开源项目按 MIT 协议「按原样」提供，使用风险自负。
