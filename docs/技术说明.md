# 技术说明

面向想改代码或做二次开发的读者。产品使用说明见 [README](../README.md)，安装步骤见 [安装教程](安装教程.md)。

## 1. 技术栈

| 项 | 选型 |
|---|---|
| 语言 | Kotlin 1.9.22 |
| 构建 | Gradle 8.9 + Android Gradle Plugin 8.2.2 |
| UI | Android Views + Material Components（无 Compose） |
| 最低 / 目标 | minSdk 24 / targetSdk 33，compileSdk 34 |
| 存储 | SharedPreferences + assets JSON |
| 网络 | **无**（Manifest 不申请 `INTERNET`） |
| 第三方依赖 | androidx core-ktx、appcompat、material、constraintlayout |

## 2. 模块划分

```text
LaunchActivity        答题锁屏，也是 LAUNCHER 入口
├─ QuestionBank       从 assets/questions.json 载入题库，按年级/学科/版本/范围过滤
├─ QuizSettings       本轮配置（时长、年级、版本、三科题量、难度、范围）
├─ WrongBook          错题本读写
├─ LockGuard          回弹与锁定态判断
└─ TimerService       前台倒计时 + 受限 App 用量检测 + 逃逸轮询

LoginActivity         家长登录 / 首次创建账号
└─ AuthStore          账号、PBKDF2、失败限流、内存会话

ParentActivity        家长首页
├─ QuizSettingsActivity   时长 / 版本 / 年级 / 三科题量 / 难度 / 错题优先
│   └─ ScopePickerActivity 册 → 单元 → 课 范围选择（Catalog）
├─ WrongBookActivity      错题本查看与移出
└─ AppLimitActivity       按 App 限时配置（AppLimitStore）

AdminReceiver         Device Admin / Device Owner 组件
BootReceiver          开机后拉起答题页
```

## 3. 关键数据

### 3.1 题库 `assets/questions.json`

```json
{
  "version": 2,
  "editions": ["通用", "人教版", "苏教版", "北师大版", "外研版", "译林版"],
  "grades": ["一年级", "..."],
  "groups": [
    {
      "grade": "三年级",
      "subject": "数学",
      "edition": "通用",
      "unit": "多位数乘一位数",
      "scopes": ["三年级|数学|上册|6"],
      "questions": [
        { "title": "38 × 8 = ?", "options": ["304", "296", "312", "288"], "answer": 0, "difficulty": 2 }
      ]
    }
  ]
}
```

- `answer` 是正确选项的**下标**（从 0 开始）。
- 题目 ID 由 `subject|grade|title` 组成，用于错题本定位。
- `scopes` 是教材目录节点 id 列表；空列表表示「不限范围」。

### 3.2 教材目录 `assets/catalog.json`

三层结构：**册 → 单元 → 课**。

```text
三年级|数学|上册              册
三年级|数学|上册|4            第 4 单元
三年级|数学|上册|4|2          第 4 单元第 2 课（lessonNo 预留）
```

目录由 `tools/fetch_catalog.py` 抓取公开目录页，再由 `tools/build_catalog.py`
通过 `MAPPING`（知识点 → 单元）写入题库分组的 `scopes`。
教材换版时只需要改映射表，不用动题库。

### 3.3 SharedPreferences

| 文件 | Key | 内容 |
|---|---|---|
| `kidlock` | `grant_minutes` | 每轮解锁分钟数 |
| `kidlock` | `quiz_grade` / `quiz_edition` | 年级 / 教材版本 |
| `kidlock` | `q_count_语文` / `q_count_数学` / `q_count_英语` | 各科题量，0 表示不抽 |
| `kidlock` | `max_difficulty` / `wrong_first` | 难度上限 / 错题优先 |
| `kidlock` | `scope_语文` / `scope_数学` / `scope_英语` | 逗号分隔的范围节点 id |
| `kidlock` | `wrong_book_v2` | 错题本 JSON 数组 |
| `kidlock` | `app_limits` | 按 App 限时配置 |
| `kidlock_auth` | `accounts` | 账号 → 密码哈希 |
| `kidlock_auth` | `login_fails` / `login_lock_until` | 登录失败计数与锁定截止时间 |

## 4. 核心流程

### 4.1 组卷

1. 读取三科配额，逐科处理；配额为 0 直接跳过。
2. 用「年级 + 学科 + 版本 + 难度上限」过滤题库。
3. 若该科选了范围，再用 `Question.inScope()` 过滤（`scopes` 为空视为不限）。
4. 开启「错题优先」时，先用该科未掌握的错题填满名额，不足部分随机补普通题。
5. 三科合并后打乱顺序，得到本轮队列。

### 4.2 答题与解锁

- 队列式：答对出队；答错 `addLast()` 回到队尾，并把错题写入错题本。
- 队列为空才算完成 → 写入 `unlock_until`，启动前台服务，结束锁屏。
- 因此「加题惩罚」不需要额外逻辑：答错几次就要多答几次，直到全部答对。

### 4.3 倒计时与回弹

- `TimerService` 每秒更新通知，并检查 `unlock_until`。
- 到期调用答题页；同时轮询当前前台包名，发现孩子离开答题页就拉回。
- 普通模式下 Home 键无法拦截，只能 `onUserLeaveHint` / `onStop` / 服务轮询三级兜底。

### 4.4 强力锁

- 通过 `dpm set-device-owner` 成为 Device Owner。
- 答题页与登录页调用 `startLockTask()`，并 `setLockTaskFeatures(NONE)`。
- 解除入口在家长页：`clearDeviceOwnerApp()`（需已登录）。
- 设上后系统拒绝 `dpm remove-active-admin`，这是 Android 的防滥用设计。

## 5. 安全模型

| 威胁 | 对策 |
|---|---|
| 孩子偷看密码 | 只存 PBKDF2 哈希，不存明文；SharedPreferences 为私有模式 |
| 孩子穷举密码 | 连续 5 次失败锁定 60 秒，计数落盘，重启不清零 |
| 时序侧信道 | 哈希比较用 `MessageDigest.isEqual` |
| 备份导出配置 | `allowBackup=false`、`fullBackupContent=false` |
| 数据外传 | 不申请 `INTERNET` 权限 |
| 孩子改设置 | 家长页强制登录；登录态为内存会话，进程结束即失效 |
| 孩子卸载 | 可选 Device Owner；普通模式无法阻止卸载 |

**密码哈希格式**：`pbkdf2$100000$<salt-base64>$<hash-base64>`。
旧版本（≤1.4）为「随机盐 + 单轮 SHA-256」，登录成功时自动重算为 PBKDF2 并删除旧字段。

**边界**：这是「提高操作成本」的家庭工具，不是不可绕过的安全产品。
拥有 adb、恢复模式或恢复出厂能力的用户始终可以解除限制。

## 6. 构建与复现

```bash
export JAVA_HOME=/path/to/jdk-17
export ANDROID_HOME=/path/to/Android/sdk
./gradlew assembleDebug
```

题库与目录的生成：

```bash
python3 tools/gen_bank.py        # 生成题库，内置答案校验
python3 tools/fetch_catalog.py   # 抓目录（需要网络）
python3 tools/build_catalog.py   # 写 scopes + 生成 catalog.json
```

`tools/gen_bank.py` 的数学题由算式生成答案，语文/英语为人工编写；
生成时会校验「4 个不重复选项 + answer 下标合法」。

## 7. 二次开发建议

- **改包名**：全局替换 `com.example.kidlock`（Manifest、源码目录、`applicationId`、
  Device Owner 命令），否则会与官方包冲突。
- **加学科**：`QuestionBank.SUBJECTS`、`QuizSettings` 的三科配额、设置页布局需同步修改。
- **换教材**：只改 `tools/build_catalog.py` 的 `MAPPING`，再跑一次生成脚本。
- **接入远程加时**：`unlock_until` 已是单一真相源，把本地读写替换为远端读写即可，
  但要注意这会引入联网权限，破坏当前的「零网络」隐私模型。
- **提高抽题精度到课**：需要按课时重建题库并给每道题写 `lessonNo`，
  当前数据结构已预留该层级，但题库尚未按课时拆分。

## 8. 已知限制

- 抽题粒度：数学 / 英语到单元，语文到整册。
- 按 App 限时依赖 `UsageStatsManager`，部分 ROM 数据延迟或不完整。
- 未做多用户 / 多孩配置，一台设备一套规则。
- UI 仅中文，未做国际化。
- `targetSdk 33`：在 Android 14 上安装会提示「专为旧版 Android 打造」，属正常现象。
